Privacy Policy

Effective date: August 1, 2026

EinkBro is an open-source web browser for Android, developed by Daniel Kao. This policy explains what data the app handles and where it goes. The short version: EinkBro does not collect, store, or share any personal data with the developer. There are no ads, no analytics, and no tracking in the app, and the developer operates no servers that receive your data.

Data Stored on Your Device

Everything the browser saves stays on your device, including:

  • Browsing history, bookmarks, and open tabs
  • Cookies and website data managed by the Android WebView
  • App settings, per-site preferences, and userscripts
  • Downloads, saved articles, and exported EPUB/PDF files
  • AI chat sessions, video transcripts, and cached translations

None of this is transmitted to the developer. You can remove it at any time with the app's clear-data options or by uninstalling the app.

Optional Features That Contact Third-Party Services

Some features send data to a third-party service, but only when you enable or invoke them. Each service processes that data under its own privacy policy:

  • Web browsing — websites you visit receive standard web requests (IP address, user agent, cookies), exactly as with any browser.
  • Search and suggestions — the text you type in the address bar is sent to your selected search engine to run the search and, if enabled, fetch suggestions.
  • AI features — when you use summarize, chat with page, translation via AI, or read-aloud with a cloud voice, the relevant page text is sent to the provider you configured (OpenAI, Google Gemini, or a custom/self-hosted server) using your own API key. Nothing is sent unless you set up a provider and trigger an action.
  • Translation — page or selected text is sent to the translation service you choose (Google Translate, Papago, or DeepL).
  • Text-to-speech — with the Microsoft Edge or OpenAI voice engines, the text to be spoken is sent to that service. The system TTS engine works entirely on-device.
  • Google Drive backup — if you enable it, backup archives are uploaded to your own Google Drive account. The developer has no access to them, and you can revoke the app's access at any time in your Google account settings.
  • Save to Instapaper — if you use it, the article and your Instapaper credentials go to Instapaper.
  • Ad blocking — filter lists are downloaded from their public hosts (e.g., AdGuard). No browsing data is sent.
  • Update check — builds distributed via GitHub contact the GitHub API to check for new releases.

Permissions

  • Location — requested only when a website asks for your location and only shared with that site after you approve both the Android permission and the site's request. The app itself never uses your location.
  • Storage / media — used to save downloads, backups, and exported files you request.

Security

API keys and service credentials you enter are stored only in the app's private storage on your device and are used solely to call the services you configured. All network connections use HTTPS.

Children

EinkBro does not collect personal data from anyone, including children.

Changes to This Policy

If this policy changes, the updated version will be published on this page with a new effective date.
