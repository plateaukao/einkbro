隱私權政策

生效日期：2026 年 8 月 1 日

EinkBro 是一款由 Daniel Kao 開發的開源 Android 網頁瀏覽器。本政策說明應用程式如何處理資料以及資料的流向。簡單來說：EinkBro 不會蒐集、儲存或與開發者分享任何個人資料。應用程式內沒有廣告、沒有分析追蹤，開發者也沒有任何接收您資料的伺服器。

儲存在您裝置上的資料

瀏覽器儲存的所有內容都只保留在您的裝置上，包括：

  • 瀏覽記錄、書籤與開啟的分頁
  • 由 Android WebView 管理的 Cookie 與網站資料
  • 應用程式設定、各網站偏好設定與使用者腳本
  • 下載檔案、儲存的文章，以及匯出的 EPUB／PDF 檔案
  • AI 對話記錄、影片逐字稿與翻譯快取

以上資料都不會傳送給開發者。您可以隨時透過應用程式的清除資料選項或解除安裝來移除。

會連線第三方服務的選用功能

部分功能會將資料傳送給第三方服務，但只在您啟用或使用該功能時才會發生。各服務依其自身的隱私權政策處理資料：

  • 瀏覽網頁 — 您造訪的網站會收到標準的網頁請求（IP 位址、使用者代理、Cookie），與任何瀏覽器相同。
  • 搜尋與建議 — 您在網址列輸入的文字會傳送給您選擇的搜尋引擎以執行搜尋，若有啟用也會取得搜尋建議。
  • AI 功能 — 使用摘要、與網頁對話、AI 翻譯或雲端語音朗讀時，相關頁面文字會以您自己的 API 金鑰傳送給您設定的服務（OpenAI、Google Gemini 或自訂／自架伺服器）。未設定服務並主動觸發時，不會傳送任何內容。
  • 翻譯 — 頁面或選取的文字會傳送給您選擇的翻譯服務（Google 翻譯、Papago 或 DeepL）。
  • 文字轉語音 — 使用 Microsoft Edge 或 OpenAI 語音引擎時，要朗讀的文字會傳送給該服務。系統 TTS 引擎則完全在裝置上運作。
  • Google Drive 備份 — 若啟用，備份檔會上傳到您自己的 Google Drive 帳戶。開發者無法存取，您也可以隨時在 Google 帳戶設定中撤銷應用程式的存取權。
  • 儲存到 Instapaper — 若使用此功能，文章與您的 Instapaper 帳號密碼會傳送給 Instapaper。
  • 廣告封鎖 — 過濾清單從其公開主機下載（例如 AdGuard），不會傳送任何瀏覽資料。
  • 更新檢查 — 經由 GitHub 發佈的版本會連線 GitHub API 檢查新版本。

權限

  • 位置 — 只有在網站要求您的位置時才會請求，且必須您同時核准 Android 權限與該網站的請求後，才會提供給該網站。應用程式本身不會使用您的位置。
  • 儲存空間／媒體 — 用於儲存您要求的下載檔案、備份與匯出檔案。

安全性

您輸入的 API 金鑰與服務憑證只儲存在裝置上應用程式的私有儲存空間，僅用於呼叫您所設定的服務。所有網路連線均使用 HTTPS。

兒童

EinkBro 不會蒐集任何人的個人資料，包括兒童。

政策變更

若本政策有所變更，更新版本會連同新的生效日期發佈在本頁面。
