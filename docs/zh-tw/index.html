EinkBro

專為 E-Ink 裝置打造的 Android 瀏覽器

為電子紙打造的無干擾瀏覽體驗：點擊螢幕邊緣或用音量鍵翻頁、以簡潔的閱讀模式閱讀，並可將文章匯出成 EPUB — 完全沒有動畫效果。

Google Play 商店 Apple App Store
GitHub Releases GitHub 搶先版 F-Droid

E-Ink 最佳化閱讀

點擊螢幕邊緣或使用音量鍵翻頁。支援閱讀模式、直書版型、自訂字型、粗體切換，並完全沒有動畫效果。

AI 整合

與網頁對話、以自由形式 Agent 執行多步驟「任務流程」、進行摘要，並以新聞主播語音朗讀文章。支援 OpenAI、Gemini、Ollama 與自訂伺服器。

使用者指令碼

內建 Tampermonkey 風格引擎，可在電子閱讀器上執行來自 Greasy Fork 的社群指令碼。支援 GM API、選單指令，並依網址自動比對套用。

儲存與匯出

匯出為包含章節與圖片的 EPUB、儲存為 PDF、封存為 MHT、擷取整頁截圖，或傳送至 Instapaper。

可自訂介面

40 個以上可設定的工具列動作，並支援拖曳排序。工具列可放在上方、下方或側邊。支援分割畫面、浮動按鈕與手勢導航。

隱私與瀏覽

內建廣告封鎖、追蹤參數清除、無痕模式，以及可依網站個別覆寫的廣告封鎖、Cookie、JavaScript 與桌面模式。
