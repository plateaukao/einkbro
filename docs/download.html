Download EinkBro

GitHub Releases

Download the latest stable APK directly from GitHub. Multiple architecture variants are available (arm64-v8a, armeabi-v7a, x86, x86_64).

GitHub Pre-release

Get the latest development build, published as a GitHub pre-release on every commit. These builds include the newest features but may be less stable.

F-Droid

Install from the F-Droid free software repository. Updates may be slightly delayed compared to GitHub releases.

Google Play Store

Install from the Google Play Store and get automatic updates. This edition uses a separate app ID, so it installs alongside the APK/F-Droid version without sharing data.

iOS App Store

EinkBro is also available for iPhone and iPad. Get it from the App Store.

Installation

  1. Download the APK for your device architecture (most E-Ink devices use arm64-v8a)
  2. On your device, go to Settings → Security and enable Unknown Sources (or allow installation from your file manager/browser)
  3. Open the downloaded APK file and tap Install
  4. Once installed, open EinkBro and start browsing

Tip: If you're unsure which architecture your device uses, download the arm64-v8a variant first — it works on most modern E-Ink devices including Boox, Kobo (with Play Store), and Kindle (with sideloading).
