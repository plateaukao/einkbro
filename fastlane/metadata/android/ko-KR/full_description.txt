EinkBro는 전자책 리더와 전자노트 태블릿 등 E-Ink 기기를 위해 설계된 가볍고 빠른 브라우저입니다.

E-Ink에 최적화된 읽기
* 화면 가장자리를 탭하거나 물리 볼륨 키로 페이지 넘기기
* 깔끔한 타이포그래피의 리더 모드
* 한자·일본어 등 CJK 텍스트를 위한 세로쓰기 모드
* 사용자 지정 글꼴, 글자 크기 버튼, 굵게 전환
* 고대비 아이콘, 애니메이션 없음

AI 통합
* 현재 페이지와 대화하고 요약하거나 다단계 에이전트 워크플로 실행
* 자연스러운 음성으로 기사 읽어 주기
* 문단별 또는 나란히 보기로 페이지 번역
* OpenAI, Gemini, Ollama 및 사용자 지정 서버 지원

유저스크립트
* Tampermonkey 스타일 내장 엔진으로 커뮤니티 스크립트 실행(예: Greasy Fork)
* GM APIs, 스크립트별 메뉴 명령, URL 자동 매칭 및 스크립트 자동 업데이트 지원

저장 및 내보내기
* 챕터와 이미지를 포함한 EPUB로 페이지 내보내기
* 목차 항목이 있는 PDF로 저장하거나 기존 PDF에 페이지 추가
* MHT로 보관, 전체 페이지 스크린샷 캡처, Instapaper로 전송

맞춤 설정 가능한 UI
* 드래그로 순서를 바꿀 수 있는 40개 이상의 툴바 동작
* 툴바를 상단·하단·측면에 배치, 한 손 사용에 최적화
* 화면 분할 보기, 플로팅 내비게이션 버튼, 고급 제스처 제어
* 무제한 탭과 전체 화면 브라우징

개인정보 보호와 브라우징
* 광고 차단기 내장
* JavaScript 및 Cookie 화이트리스트
* 추적 매개변수 제거, 시크릿 모드, 사이트별 데스크톱 모드

사용될 수 있는 권한
* INTERNET: 브라우저이므로 필요합니다.
* READ_EXTERNAL_STORAGE, WRITE_EXTERNAL_STORAGE: 웹 페이지를 PDF나 EPUB 파일로 저장하고 파일을 다운로드하는 데 사용됩니다.
* INSTALL_SHORTCUT: 홈 화면에 웹 바로가기를 추가하는 데 사용됩니다.
* ACCESS_FINE_LOCATION, ACCESS_COARSE_LOCATION: 웹사이트가 위치 정보를 요청할 때만 사용됩니다.
